# NagiHub

A clean, mobile-friendly Roblox in-game utility hub for Team Zyvora.

## What it is

NagiHub is designed for experiences you own or are developing in Roblox Studio. It uses normal Roblox APIs and does not depend on executors, `loadstring`, or external exploit loaders.

## Features

- Modern NagiHub UI
- Mobile + desktop responsive layout
- Home, Player, Visuals, and Settings tabs
- WalkSpeed and JumpPower controls
- Sprint toggle
- Full-screen UI toggle
- Player list / quick teleport UI for your own test experience
- Clean notification system
- Easy-to-extend feature modules

## Installation

1. Open your Roblox Studio experience.
2. Create a `LocalScript` under `StarterPlayer > StarterPlayerScripts`.
3. Copy `src/NagiHub.client.lua` into that LocalScript.
4. Press Play to test.
